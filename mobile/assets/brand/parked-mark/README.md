# Parked mark

The two-person-heart mark: the five former brand SVG sources, `logo-mark.svg` (formerly `web/`) and, in `drafts/`, later explorations.
Parked on 2026-10-28 because the owner has not yet found a mark he likes; the brand is the text wordmark "LocalBuddy" for now.
To restore: move the five SVGs back to `mobile/assets/brand/` and `logo-mark.svg` back to `web/`, restore the header
`<img class="mark">` and the `<link rel="icon">` in both landing pages, then run `node .claude/tools/render-brand.mjs`.
Known catch: the Night-coloured figure vanishes on a Night background, so any mark with a Night half needs an on-dark
variant (the `-dark` drafts show one).
